              When you're ready

              • Use it from your phone or ChatGPT on the web

                Phone and web apps can only reach a public https address, so they need a hub that lives on the internet: your own Cloudflare hub, or this program running behind a tunnel. The steps are in docs/SELF-HOST.md.

              • Make it a habit

                Paste this into each app's custom instructions so it recalls and saves on its own.

                Use Legendary Memory: recall a project before working on it and save a checkpoint when we finish a session.
              • Undo everything

                This removes the connection from each app and restores the settings as they were.

                node ~/.legendary-memory/bin/legendary-memory.mjs setup --undo
