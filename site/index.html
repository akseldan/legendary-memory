Good to know

Where does my memory live?

In one file on your computer, ~/.legendary-memory/memory.db. Nothing is sent anywhere and there is no account. Back it up by copying the file.

Which apps does it work with?

Claude Desktop, with this download. Claude Code, Codex, Cursor, Windsurf and Gemini CLI connect through the Terminal command above (Mac and Linux; it brings its own copy of Node.js). Claude on the web and phone, and ChatGPT, need a version that lives on the internet, which you run yourself on Cloudflare's free plan; the steps are on GitHub.

How do I remove it?

Open Claude Desktop, go to Settings, then Extensions, and remove Legendary Memory. If you used the Terminal command, run legendary-memory uninstall; it disconnects every app and puts their settings back. Your saved memory file stays until you delete it.

Can I see or delete what it saved?

Yes. Ask any connected assistant to show or forget something, or run the welcome page from the GitHub project to browse, edit and delete your projects.

Is it finished?

This is version 1. The Claude Desktop install and the Claude Code connection are tested on a Mac. Other apps, Windows, and the self-hosted versions pass automated tests but are newer, so expect rough edges and tell us on GitHub.
