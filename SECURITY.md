# Security

Please report security problems privately. Use **Security → Report a vulnerability** on this repository, or email the maintainer through the address on their GitHub profile. Don't open a public issue for a vulnerability.

Include what you found, how to reproduce it, and which version you used (`legendary-memory --version`, or `/api/health` on a hub). Expect a first reply within 7 days.

What the project defends against, and how it's tested, is in [docs/contracts/THREAT-MODEL.md](docs/contracts/THREAT-MODEL.md). What an owner does when something goes wrong is in [docs/RUNBOOKS.md](docs/RUNBOOKS.md).
